# HuiLiao_WeChat 项目结构（Step 1）

```text
HuiLiao_WeChat/
├── assets/                  # 模板图、UI截图、调试样本
├── config/                  # settings.yaml 等配置文件
├── core/                    # 视觉识别、窗口管理、控制器、LLM客户端
├── features/                # 业务流程模块（如聊天回复）
├── ui/                      # Streamlit 可视化控制台
├── docs/                    # 需求分解、资产清单、架构文档
└── requirements.txt         # Python 依赖
```

> 当前为第一步脚手架与规范阶段，后续步骤将按模块逐步填充实现。
